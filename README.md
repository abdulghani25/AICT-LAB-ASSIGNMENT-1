# AICT Lab Assignment - University Website

## Project Description
This assignment is a static University Website developed as part of the AICT Lab Assignment. It provides information about the university, its departments, academic programs, and other details.

The website is developed using:
- HTML
- CSS
- JavaScript

## Instructions for Running the Project

1. Download or clone this GitHub repository.
2. Open the downloaded project folder.
3. Open the folder named `AICT LAB (ASSIGN 1) - ABDUL GHANI`.
4. Find the `index.html` file.
5. Double-click `index.html` to open the website in your web browser.

No additional software or installation is required.
